BIRTHDAY SURPRISE — QUICK SETUP

1. Open index.html in a browser to preview.
2. Change HER NAME in script.js:
   const BIRTHDAY_NAME="Her Name";
3. Photos:
   You can click the photo placeholders while viewing the site and select photos from your phone.
   For permanent photos, put them in images/ and edit the HTML image paths.
4. Music:
   Put an MP3 in this folder and add:
   song.src="your-song.mp3";
   near the bottom of script.js.
   Only use music you have the right to use/share.
5. Deploy:
   Upload these files to a GitHub repository and enable GitHub Pages.
   The site is static and needs no server/database.
